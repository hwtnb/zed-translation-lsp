# 使い方

[English](../usage.md)

このページでは、翻訳を依頼する、読む、取り消す、再試行する方法と、送信する文章を説明します。処理の受付、継続、キャッシュの規則は[動作](behavior.md)で説明します。

## コメントのホバー

対応するコードのコメントにマウスポインターを重ねるか、カーソルを置いてZedの `editor: hover` を実行します。同じ種類・字下げの隣接した行コメントはまとめて訳し、空行やコードを挟むと分けます。ブロックコメントは一つずつ扱います。コメント記号と直後のASCIIスペース一つを除いた本文を翻訳します。

複数行のブロックコメントとdocstringは、行頭の余白も除いて送ります。`/*` で始まるコメントでは、`/**` や `/*!` の残りのように `*` と `!` だけでできた1行目を除きます。また、2行目からあとの空行でない行がすべて `*` で始まる場合は、その `*` と直後の空白かタブ一つを除きます。続けて、2行目からあとの行に共通する字下げ、1行目の行頭の空白とタブ、最初と最後の空行、最後の行の末尾の空白とタブを除きます。行どうしの相対的な字下げと、間の空行は保ちます。

翻訳先の言語ですでに書かれたコメントには、ホバーを表示しません。これを判断するのはモデルか翻訳サービスで、[送信する内容](#送信する内容)で説明します。サーバーが自分で言語を推測することはありません。サーバーはこの答えを訳文と同じように覚えておくので、文書を変えるまでは、同じコメントにもう一度ポインターを重ねても送りません。CodeLensの `Translate` とコードアクションは、いつでもコメントを翻訳します。

ホバーの位置と幅はZedが決めます。上側への固定や、本文を完全に隠さない配置は保証しません。

## Markdownの選択

[プロバイダーの設定](../../README.ja.md#プロバイダーの設定)のとおりプロバイダーが使える状態で、`features.automatic_selection` が `true` の場合、Markdownの文章を選択して安定させるとバックグラウンドで翻訳します。既定ではZedから選択が届いた後に450ms待ち、Zed側の観測待ちも別に加わります。その範囲でホバーを開いて訳文を読みます。バックグラウンド翻訳の完了通知は表示しません。翻訳先の言語ですでに書かれた文章には、[コメントのホバー](#コメントのホバー)と同じく、ホバーを表示しません。コードアクションは、いつでも翻訳します。

コードやリンク先だけ・空白だけの選択では開始しません。コードの囲みなどを途中で切り、選択部分だけでは構文の解釈が変わる範囲も自動対象外です。囲みを含めて選び直すか、手動翻訳を使ってください。

選択した文章はコピー目的の場合も送信され得ます。

## 手動の選択翻訳

すぐに実行したい場合やバックグラウンド翻訳が失敗した場合は、コードアクションの `Translate selection to …` を使います。このコードアクションは、完了すると通知 `Translation ready. Hover over the selected text to view it.` を表示します。コード言語やMarkdown以外でも範囲選択による翻訳を使えます。ChatGPTプロバイダーで未接続またはプラン利用が無効の場合は、`ChatGPT account…` から接続・利用許可を実行してください。Anthropic APIまたはOpenAI APIのプロバイダーでキーが保存されていない場合は、`Anthropic API key…` または `OpenAI API key…` からキーを保存してください。選択がないとホバー用の翻訳項目は表示されません。

## 単語を辞書で引く

1行で3語以下、64文字以下の選択は、末尾が `.`、`!`、`?`、`。`、`！`、`？` でなければ、翻訳する代わりに辞書で引きます。`retain`、`take over`、識別子の `retain_completed` などです。語はUnicodeの単語境界で数えるため、空白で区切らない言語も区切って数えます。日本語では助詞や語尾も1語に数え、`保持する` は2語、`設定を保存する` は4語です。選択範囲にマウスポインターを重ねると、辞書の項目が表示されます。項目には、語と、品詞を添えた意味（その行での意味が先頭）、識別子や複合語を分けた各語の意味と全体の意味、例文とその訳を含めます。Markdownの自動の選択、`Translate selection to …`、`… and open in tab` のどれにも当てはまります。文書全体を選択した場合は、`Translate document to … and open in tab` と同じく翻訳します。コメントのホバーで読むコメントは、1語でも辞書で引きません。DeepL APIとGoogle Cloud Translationは辞書の項目を書かないため、これらではこのような選択もほかと同じように翻訳します。

`Example:` などの項目の見出しは英語です。意味と品詞は翻訳先の言語で書きます。

## ホバーでの訳文の表示

ホバーには、見出しの `Translation LSP` と、その下の区切り線に続けて訳文を表示します。`hover.header` を `false` にすると、訳文だけを表示します。[ホバーの表示](configuration.md#ホバーの表示)を参照してください。

コメント、コードの中の選択、Plain Textの訳文は、訳文の次の書式を生かしたMarkdownとして表示します。

- コードスパンと、囲みのあるコードブロック、空行のあとの字下げによるコードブロック
- `#` で始まる見出しと、`===` や `---` の下線による見出し
- `-`、`*`、`+`、番号で始まるリスト(字下げしたものも)、引用、表、区切り線
- `*` と `**` による強調と、`~~` による取り消し線
- `[文字](URL)` の形のリンクのうち、原文にあるURLへのもの

ほかの文字は、書かれたとおりに表示します。`__init__`、`--verbose`、`\d+\.\d+`、`Vec<T>`、`<!-- note -->`、`~a~`、`[^1]` はそのまま表示し、引用符や `...` も組版用の記号に置き換えません。訳文の改行は、表示でも改行します。空行は、いくつ続いても1つの段落の区切りになります。段落の中の行頭の空白は表示しません。この方法で書式を生かせない訳文は、書式を付けずに各行を書かれたとおりに表示します。

リンクで開けるのは、原文にあるURLだけです。原文の中のモデルへの指示によって、原文にないリンクが訳文に入ることがあるためです。原文のURLは、`.` や対応しない `)` など、周りの文の句読点の前で終わります。訳文では、次のようになります。

- URLだけを書いた部分は、原文のURLで始まり、その後で文が終わるか、空白かASCII以外の文字が続く場合に、リンクになります。間に句読点があってもかまいません。`詳細はhttps://example.com/docsを参照` では、`https://example.com/docs` がリンクになります。
- `[文字](URL)` や `<URL>` の形のリンクは、URLが原文のURLのどれかと完全に一致する場合に残ります。
- 空白を挟まずにURLが2つ続く部分は、クエリーの中に別のURLを含むURLなども含めて、リンクになりません。

ほかのURLは、`:` の後に見えない文字（U+2060、WORD JOINER）を入れて文字として表示し、ホバーからコピーした文字にもこの文字が含まれます。コードの中のURLは書かれたとおりに表示し、リンクにしません。

`hover.format` が `"markdown"` の場合、Markdownの文書の訳文は、訳文のMarkdownのまま表示します。リンクと画像は、リンク先が原文のリンク先のどれかと完全に一致するか（同じ相対パスなど）、`#` で始まる場合に残します。ほかのリンク先や、`https&#58;//` のようにエスケープや文字参照で分かれたURLがあると、代わりにコードブロックの中に書かれたとおりに表示します。URLだけを書いた部分は上の規則に従い、画像の代替テキストの中のURLはリンクにしません。辞書の項目は、[単語を辞書で引く](#単語を辞書で引く)のとおりに表示します。`hover.format` を `"text"` にすると、辞書の項目を除くすべての訳文を、コードブロックの中に書かれたとおりに表示します。

## 翻訳をタブに開く

Markdownまたはプレーンテキスト（Zedの言語名は `Plain Text`）では、`Translate selection to … and open in tab` で訳文を別タブに開けます。選択がない場合は `Translate document to … and open in tab` となり、文書全体を翻訳します。どちらも `translation_limits.input_kib.document` の上限を使い、既定は1 MiBです。クライアントには `window/showDocument` 対応が必要です。

別タブに開く翻訳は、コマンドを受け付けた後も処理を続け、完了時に結果を開きます。全文・選択範囲とも、キュー待ちとは別に既定3分の実行期限があります。文字数による自動延長はしません。範囲単位・全件を取り消すコードアクションで止められます。元の文書を編集・閉じた場合も結果を開きません。

Markdownの訳文は一時的な `.md` ファイルとして開きます。コマンドパレットの `markdown: open preview` で整形された表示にし、必要に応じてソースタブへ戻れます。プレーンテキストの訳文は `.txt` で開きます。通常のMarkdownの開き方は変更しません。開いた訳文はその時点の内容で、原文の編集には追従しません。必要なときに再び翻訳操作を実行してください。

残したい訳文は、言語サーバーの再起動やZedの終了前に「別名で保存」してください。一時ファイルはサーバーの正常終了時に削除します。異常終了した場合はシステムの一時フォルダーに残ることがあります。別名保存したファイルは削除しません。

相対パスのリンクや画像は一時ファイルの位置を基準に解決します。元の相対パスを使う場合は、原文と同じフォルダーへ別名保存してください。

訳文はモデルの出力です。原文の中にモデルへ向けた文章があると、原文にないリンクや画像が訳文に入ることがあります。`markdown: open preview` は、`http` と `https` の画像をそのURLから読み込んで表示します。そのため、URLに訳文の一部が入っていれば、URLが指すサーバーにその部分が届きます。他人が書いた原文では、プレビューを開く前に、訳文のタブをテキストのまま確かめてください。

同じキャッシュ済み翻訳を再びタブに開く場合は、一時ファイルを再利用してその文書へ移動します。ファイルが削除された場合や保存済みの内容が変更された場合は、既存の内容を上書きせず新しいファイルを作ります。新しく翻訳した結果は別ファイルになります。一時ファイルはサーバー終了時に削除し、「別名で保存」で保存したコピーは残します。

## CodeLens

Zedの設定で `"code_lens": "on"` にすると、本文の上の行に短いコマンドを表示します。Zedの既定値は `"off"` です。Zedは同じ行のコマンドを `|` で区切って1行に並べます。

| 場所 | 表示する行 |
| --- | --- |
| 訳文のないコードのコメント | `Translate \| Settings` |
| 翻訳済みの範囲 | 訳文の1行目（72文字まで）と、コードでは `Settings` |
| 翻訳に失敗した範囲 | `Translation failed \| Retry` と、コードでは `Settings` |
| 翻訳中の範囲 | `Translating… \| Cancel` と、コードでは `Settings` |
| Markdownとプレーンテキストの1行目の上 | `Translation LSP: Translate in tab \| Auto-translate: On \| <アカウントメニュー> \| Zed settings` |

`Translate` は、`Translate selection to …` と同じようにコメントを翻訳します。プロバイダーが使える状態で、`selection_action` が有効なときに表示します。ホバーで翻訳先の言語だとわかったコメントも、`Translate` のままです。`Retry` は、失敗した範囲をもう一度翻訳します。どちらのあとも、行に訳文を表示し、コードアクションで出す完了通知 `Translation ready. Hover over the selected text to view it.` は出しません。同じ範囲をコードアクションでも待っている場合は、完了通知を出します。翻訳済み、失敗、翻訳中の範囲は、コメントのホバー、選択、`Translate` で翻訳した範囲です。タブに開く翻訳には行を表示しません。文書を編集すると、訳文が無効になった範囲の行は消えます。

訳文の1行目をクリックすると訳文の全体を、`Translation failed` をクリックすると失敗の理由をカードに表示します。カードは閉じるまで残ります。カードの `Retry translating this text` ボタンで、その範囲をもう一度翻訳します。新しい訳文はCodeLensに表示し、完了通知は出しません。カードにあるZedのコピーボタンは、本文をMarkdownのままコピーします。記号の前のバックスラッシュと、前後の `---` の行も含みます。

`Translate in tab` は、`Translate document to … and open in tab` と同じように文書全体を翻訳します。プロバイダーが使える状態で `document_action` が有効なときに、`window/showDocument` に対応したクライアントで表示します。アカウントメニューの項目は、`ChatGPT account…` などのプロバイダーのアカウントメニューです。`Zed settings` はZedの設定ファイルを開きます。これも `window/showDocument` に対応したクライアントでだけ表示します。

`Settings` は、同じ項目のメニューを開きます。項目は `Turn off automatic translation` または `Turn on automatic translation`、アカウントメニュー、`Open Zed settings file` です。自動翻訳をオフにすると、言語サーバーを再起動するまで、コメントのホバーとMarkdownの自動選択では翻訳を始めません。それらが始めた翻訳のうち、ほかから求められていないものは取り消します。翻訳済みの訳文はホバーに表示し、`Translate`、コードアクション、タブに開く翻訳はそのまま使えます。Markdownとプレーンテキストの上の `Auto-translate: On` でも同じようにオフにでき、表示は `Auto-translate: Off` に変わります。

コメントの多いファイルでは、コメントごとに行が増えます。[`features.comment_lens`](configuration.md#機能の切り替え) を `false` にすると、訳文、失敗、翻訳中のどれもないコメントには行を表示せず、メニューをMarkdownと同じように1行目の上に表示します。

## 状態表示と通知

翻訳の待機・実行中は、ステータスバー左側にスピナー（回転する処理中の印）と文字を直接表示します。`Queued: …` は待機中の件数、`Translating: …, queued: …` は実行中と待機中の件数です。同じ範囲への複数の要求は一件と数えます。`provider.document` を設定している場合と、Anthropic API、OpenAI API、OpenAI互換のプロバイダーで範囲翻訳の要求を送った後の場合は、その範囲のタブ翻訳を別に数えます。この欄はほかの言語サーバーと共有するため、別の活動が優先されることがあります。

スピナーは取り消しや時間切れを含め、作業が終わると消えます。結果は原文へのホバーで確認してください。状態表示に対応するクライアントでは、翻訳失敗・時間切れの警告が残り、再試行・編集・文書の閉鎖で消えます。これらの表示に対応しない場合も、ホバーと明示操作の通知を使えます。

明示操作の完了・失敗通知にはファイル名と行番号を付けます。自動翻訳の完了ポップアップは出しません。明示した翻訳や管理操作が失敗した場合は、エラー通知を確認してください。

文書のコメントを読み取れなかった場合は、次のどちらかの警告を表示します。同じ文書では、開き直すまで1回だけです。`<file>` はファイル名です。[コメントを読み取れなかった文書](languages.md#コメントを読み取れなかった文書)を参照してください。

| 警告 | 原因 |
| --- | --- |
| `Reading comments in <file> timed out. Comments in this file are not recognized until you reopen it. To allow more time, adjust comment_parse_timeout_ms in Zed settings.` | 読み取りが `comment_parse_timeout_ms` を超えた。 |
| `Reading comments in <file> failed. Comments in this file are not recognized until you reopen it.` | 読み取りがサーバーの中で失敗した。 |

## 取り消しと再試行

1件を止めるには、その範囲にカーソルか選択範囲を置き、コードアクションの `Cancel translation of lines …` を実行します。`provider.document` を設定している場合、タブ翻訳は `Cancel tab translation of lines …` と表示するため、同じ範囲に両方のアクションが並ぶことがあります。片方を取り消しても、もう片方は続きます。

`Cancel all translations` はアカウントメニューを残してすべての翻訳を取り消します。以前の取り消しアクションを再実行しても、同じ範囲の新しい依頼には影響しません。クライアントが進捗の取り消し操作を表示すれば、それでも全件を取り消せます。Zedの進捗操作とアクション一覧の更新は、実機では未確認です。取り消しには主にコードアクションを使ってください。

失敗範囲内にカーソルを置き、Code Actionsから `Retry translation of lines …` を選ぶと、文章を選び直さずに記録された範囲を再試行できます。利用上限で停止した後も、明示的な再試行として扱います。ホバーだけでは失敗表示を維持します。

## 送信する内容

完成した訳文は、[ホバーでの訳文の表示](#ホバーでの訳文の表示)のとおりに表示します。選択した文章をまとまりとして渡し、意味、コード、識別子、URLを保って訳文だけを返すようモデルに指示します。文章は翻訳する対象として区切って渡し、文中に指示や質問があっても、従ったり答えたりせずに訳すよう指示します。訳文をJSONの断片へ分けたり、Markdownの書式や改行の違いを理由に拒否したりしません。この指示によって翻訳の正確さを保証するものではありません。DeepL APIとGoogle Cloud Translationは指示文を受け付けません。サーバーは文章を区切り、コードとURLに印を付けて送り、訳文を組み立て直します。DeepL APIのページの[送信する内容](providers/deepl.md#送信する内容)で説明します。

コメントのホバーとMarkdownの自動の選択では、`source_language` が `auto` のとき、モデルに次のことも指示します。コード、識別子、URLを除いた文章の全体が、すでに翻訳先の言語で書かれていれば、`<same_language/>` だけを返すこと。ほかの言語の文が一つでもあるとき、または迷ったときは、いつもどおり全体を翻訳すること。サーバーはこの応答には何も表示しません。ほかの文字を含む応答は、訳文として表示します。DeepL APIとGoogle Cloud Translationは、区切りごとに検出した原文の言語を返します。すべての区切りが翻訳先の言語のとき、サーバーは何も表示しません。明示の翻訳と辞書の検索では、この指示を送りません。`source_language` に言語を指定したときも送りません。自動の翻訳の応答を待つ間に、同じ範囲でコードアクションなどの明示の翻訳を実行し、その文章が翻訳先の言語だと判断された場合は、同じ文章をもう一度、明示の翻訳として送ります。

辞書で引く場合は、語と、それとは区切って、語のある行（語の前後それぞれ最大200文字）をモデルに渡します。意味、語の内訳、例文をJSONのオブジェクトで返すよう指示します。サーバーはそのオブジェクトから項目を組み立て、応答の文字列をすべてエスケープするため、応答によってホバーにリンク、画像、その他の書式が加わることはありません。そのようなオブジェクトでない応答はエラーとして報告します。コードアクションから再試行してください。

手動の選択翻訳・全文翻訳は、字下げやコードだけの内容でも指定した文章を送信します。コードや識別子の保持はモデルに指示します。Markdownの散文判定はバックグラウンドでの自動翻訳だけに適用し、翻訳プロバイダーへ送らずに原文を翻訳成功として表示することはありません。

翻訳プロバイダーへ送る文章は、抽出したコメント本文([コメントのホバー](#コメントのホバー)で説明した記号と余白を除いたもの)、選択範囲、または文書翻訳を明示した場合の文書全体です。辞書で引く場合は、語のある行も送ります。会話履歴は送りません。訳文を原文へ書き戻すこともありません。
